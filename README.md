# URL History Eraser

 Chrome 插件（Manifest V3）。指定一批网址后，正常浏览这些网址及其子网址时：

- 浏览器历史记录里查不到访问痕迹（历史页、地址栏联想、新标签页常用网站、最近关闭的标签页）；
- 访问记录不会留在同步数据里，其他已登录设备上也查不到；
- 登录状态、Cookie、站点会话完全不受影响。

## 工作原理

Chrome 没有提供"阻止某个网址写入历史"的扩展接口，所以插件采用**写入后立即删除**：

| 层 | 触发时机 | 作用 |
|---|---|---|
| T0 | `history.onVisited`（历史一写入就触发） | 立即删除，时间窗最短 |
| T1 | 标签页的 URL、加载状态、标题、图标变化 | 兜底 404 页面等不触发 T0 的情况；2 秒后补删一次，清掉延迟写入的 favicon |
| T2 | 标签页关闭、最近关闭列表变化 | 清理"最近关闭的标签页"中的受保护条目 |
| T3 | 浏览器启动 1 分钟后、每 15 分钟、每 24 小时、新增规则时、手动 | 清扫残留记录 |

`chrome.history.deleteUrl` 在开启历史同步时会同时生成同步删除指令，所以其他设备上的记录最终也会被删除。插件不调用任何 Cookie 或站点数据相关的接口，登录态因此保持不变。

## 安装

1. 打开 `chrome://extensions`，开启右上角的"开发者模式"。
2. 点击"加载已解压的扩展程序"，选择本项目的根目录（`manifest.json` 所在的目录）。
3. 安装后会自动打开设置页。

要求 Chrome 120 或更高版本。

## 使用

### 弹窗

点击工具栏图标：

- 查看当前网站是否受保护、命中了哪条规则；
- 选择保护范围（如 `mail.example.com` 或 `example.com`）、是否包含子域名、是否只保护当前路径，然后点"加入保护"；
- 已受保护的网站可以"移除保护"（需要点两次确认）；
- "立即清扫"手动执行一次清扫。

受保护的网址不会出现在地址栏联想中，请用书签或设置页里规则旁的"打开"进入。

### 设置页

- **保护规则**：输入域名或完整网址添加规则，输入时会实时显示规范化结果和"会命中 / 不会命中"的示例；可以开关子域名、启用 / 停用、编辑备注、删除。
- **清扫**：查看上次清扫时间，手动执行快速清扫或全量清扫。
- **选项**：新增规则时是否清除既有记录、是否清理最近关闭的标签页、是否清理下载记录、是否显示保护指示、快速清扫间隔。
- **同步设置**：说明同步相关的限制，并提供打开 Chrome 同步设置的按钮。
- **导入 / 导出**：规则以 JSON 文件导入导出。

### 规则怎么匹配

| 输入 | 规则 | 会命中 | 不会命中 |
|---|---|---|---|
| `example.com` | `*.example.com` | `example.com/...`、`a.example.com/...` | `notexample.com` |
| `example.com/foo` | `example.com/foo` | `example.com/foo`、`example.com/foo/bar?x=1` | `example.com/foobar`、`www.example.com/foo` |
| `example.com:8080` | `*.example.com:8080` | `example.com:8080/...` | `example.com/...`（其他端口） |

- 纯域名规则默认包含子域名，带路径的规则默认不包含（都可以手动改）。
- 路径按"段"匹配，区分大小写；查询串和 `#` 片段不影响匹配。
- http 与 https 都命中。国际化域名用中文或 punycode 输入都可以。

### 快捷键

可以在 `chrome://extensions/shortcuts` 为"切换当前网站的保护状态"绑定快捷键（默认未绑定）。

### 状态提示

| 图标 / 徽标 | 含义 |
|---|---|
| 绿色图标 | 当前标签页受保护（可在设置中关闭此提示） |
| 徽标 `OFF` | 插件全局开关已关闭 |
| 徽标 `!`（红色） | 浏览器策略禁止删除历史，插件无法工作 |

## 推荐的同步设置

| 档位 | 需要做的 | 效果 |
|---|---|---|
| 标准 | 无 | 本机查不到；其他设备上的历史在同步删除后消失；受保护页面**开着时**其他设备能在"其他设备的标签页"中看到 |
| 严格 | 在 `chrome://settings/syncSetup/advanced` 关闭"历史记录"和"打开的标签页" | 受保护网址完全不上传 |

如果 Google 账号的"网络与应用活动记录"包含 Chrome 历史，严格场景下也建议关闭。

## 已知限制

- **不是零写入**：记录会先写入再被立即删除，中间有极短的时间窗；开启历史同步时，记录可能在这个时间窗内被上传，之后才被删除指令清掉。
- **"打开的标签页"同步无法拦截**，只能按上表关闭。
- **站点数据保留**：为了保持登录，Cookie 等数据不会清除，域名会出现在 Chrome 的"网站数据"列表中。
- **关联网址需要另加规则**：登录时跳转经过的第三方域名（如统一登录）、在搜索引擎上搜索该网站留下的搜索页记录。
- **规则列表明文保存**在本机，打开设置页即可看到。
- **受管设备可能无法使用**：企业策略禁止删除历史时，插件会显示红色 `!` 并停止工作。
- **网络层与磁盘取证不在防护范围内**（路由器、代理、DNS 记录，SQLite 已删除数据的恢复）。

## 副作用

这些来自 Chrome 删除历史时的联动清理，不是插件主动行为：

- 标签页的后退 / 前进记录中，同一网址的旧条目可能被移除；
- 每次真正删除历史时，Chrome 会清空"上次会话"的恢复数据。浏览器启动后的清扫因此延迟 1 分钟，避免影响会话恢复；
- 一个标签页先访问了普通网址、后访问了受保护网址，关闭后整条"最近关闭"记录会一起消失（普通网址仍在历史记录里）；
- 该站点自动生成的站内搜索引擎条目会被删除。

## 权限

| 权限 | 用途 |
|---|---|
| `history` | 监听访问、查询和删除历史 |
| `tabs` | 读取标签页网址（兜底删除、弹窗、保护指示） |
| `sessions` | 读取最近关闭的标签页 |
| `storage` | 保存规则和设置 |
| `alarms` | 定时清扫 |
| `downloads`（可选） | 仅在开启"清理下载记录"时请求 |

不申请任何网站访问权限，不注入脚本，读不到网页内容；不申请 `cookies`、`browsingData`。

## 隐私

- 插件不发起任何网络请求。
- 规则只存在本机（`chrome.storage.local`），不使用同步存储。
- 不记录被删除的网址，日志中不输出网址。运行期间需要的临时状态（例如标签页访问过的受保护网址）只放在内存（`chrome.storage.session`），浏览器退出即清空。
- 插件自身的设置页、弹窗页在标签页中打开时产生的历史记录也会被删除。

### 目录结构

```
├── manifest.json
├── _locales/                  中文（默认）与英文文案
├── icons/                     由 tools/gen-icons.mjs 生成
├── src/
│   ├── background/
│   │   ├── service-worker.js  入口：注册监听器、启动、定时任务、消息、快捷键
│   │   ├── eraser.js          T0 / T1 即时清除与补删
│   │   ├── closer.js          T2 最近关闭清理
│   │   ├── sweeper.js         T3 快速清扫 / 全量清扫（可续跑）
│   │   ├── tab-tracker.js     标签页 → 受保护网址（仅内存）
│   │   ├── downloads.js       下载记录清理（可选）
│   │   ├── indicator.js       图标、徽标、"删除被禁止"状态
│   │   ├── state.js           规则与设置的缓存
│   │   └── util.js
│   ├── shared/
│   │   ├── rule.js            规则解析、规范化、校验（纯函数）
│   │   ├── matcher.js         索引与匹配（纯函数）
│   │   ├── store.js           storage 封装
│   │   ├── i18n.js
│   │   ├── constants.js
│   │   └── base.css
│   ├── popup/
│   └── options/
└── tools/gen-icons.mjs
```
